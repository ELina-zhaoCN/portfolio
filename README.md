# Rulian Zhao — Personal Portfolio

Personal portfolio website for job search and academic applications.

## About

Static single-page site showcasing product management experience, research projects, and education background.

**Sections:** Hero · About · Projects · Research · Education

## Run Locally

No build step needed — it's plain HTML.

```bash
# Option 1: open directly
open index.html

# Option 2: use VS Code Live Server extension
# Right-click index.html → Open with Live Server

# Option 3: Python simple server
python3 -m http.server 8080
# then visit http://localhost:8080
```

## Tech Stack

- HTML5 + Tailwind CSS (CDN)
- Google Fonts (Inter, Playfair Display)
- No JavaScript frameworks, no build tooling
